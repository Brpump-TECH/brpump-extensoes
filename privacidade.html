Política de Privacidade

Aplicável a todas as extensões do Chrome publicadas pela BR Pump.

Última atualização: 26/07/2026

1. Dados coletados

Nossas extensões não coletam, armazenam nem transmitem dados pessoais de usuários a terceiros.

2. Armazenamento local

Quando necessário, as extensões armazenam configurações e credenciais exclusivamente no dispositivo local do usuário, utilizando o mecanismo chrome.storage.local do próprio navegador. Essas informações nunca saem do dispositivo para servidores externos não autorizados.

3. Comunicação externa

As extensões se comunicam apenas com serviços e APIs explicitamente autorizados pelo usuário, utilizando as credenciais fornecidas pelo próprio usuário. Nenhuma comunicação é realizada com servidores da BR Pump ou terceiros.

4. Permissões do navegador

As permissões solicitadas por cada extensão são utilizadas exclusivamente para as funcionalidades descritas na página da extensão na Chrome Web Store. Nenhuma permissão é utilizada para fins de rastreamento ou coleta de dados.

5. Compartilhamento de dados

Nenhum dado do usuário é compartilhado, vendido ou transferido a terceiros.

6. Alterações nesta política

Esta política pode ser atualizada periodicamente. A data da última atualização será sempre indicada no topo desta página.

7. Contato

Em caso de dúvidas sobre privacidade, entre em contato: comercial@brpump.com.br
