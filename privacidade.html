Política de Privacidade

Aplicável a todas as extensões do Chrome publicadas pela BR Pump.

Última atualização: 29/07/2026

Extensões cobertas por esta política

  • BR Pump — Proposta Comercial: gera propostas comerciais em PDF a partir de pedidos do Omie ERP.
  • BR Pump — Dash Comercial: exibe indicadores comerciais (faturamento, devoluções, desconto praticado, contas a receber em atraso, conversão de propostas e quadro de premiação) a partir de dados da API do Omie ERP.

Ambas são de uso interno da BR Pump Indústria e Comércio de Bombas Ltda. e exigem credenciais de API do Omie fornecidas pela própria empresa.

1. Dados coletados

Nossas extensões não coletam, armazenam nem transmitem dados pessoais de usuários a terceiros. Não há coleta de histórico de navegação, localização, dados de saúde, informações financeiras pessoais, comunicações pessoais ou conteúdo de outros sites.

2. Armazenamento local

Quando necessário, as extensões armazenam informações exclusivamente no dispositivo local do usuário, por meio do mecanismo chrome.storage.local do próprio navegador:

  • credenciais de API do Omie (App Key e App Secret);
  • preferências de uso, como período consultado, categorias de produto, metas, equipe da premiação e demais parâmetros de exibição;
  • cópia temporária (cache) dos dados consultados no ERP, para acelerar a abertura das telas e reduzir o número de chamadas à API.

Essas informações não são enviadas para servidores da BR Pump nem de terceiros.

3. Configuração distribuída pela organização

Em máquinas gerenciadas pela BR Pump, parte dessas configurações pode ser distribuída pelo administrador por meio de política corporativa do Google Workspace, sendo lida pela extensão através de chrome.storage.managed (somente leitura). Nesse caso, os valores são definidos e mantidos pela própria empresa em seu ambiente administrativo.

4. Comunicação externa

As extensões se comunicam apenas com a API do ERP Omie (https://app.omie.com.br), utilizando as credenciais fornecidas pela empresa. Não há uso de serviços de análise, rastreamento ou publicidade, nem comunicação com servidores da BR Pump ou de terceiros.

5. Permissões do navegador

As permissões solicitadas por cada extensão são utilizadas exclusivamente para as funcionalidades descritas na página da extensão na Chrome Web Store. Nenhuma permissão é utilizada para rastreamento ou coleta de dados. As extensões não injetam conteúdo nem leem páginas de outros sites.

6. Compartilhamento de dados

Nenhum dado do usuário é compartilhado, vendido ou transferido a terceiros. Os dados não são utilizados para finalidade alheia ao propósito de cada extensão, nem para determinar capacidade de crédito ou conceder empréstimos.

7. Retenção e exclusão

Os dados permanecem no navegador enquanto a extensão estiver instalada. O usuário pode apagá-los a qualquer momento removendo a extensão ou limpando os dados do navegador. O acesso ao ERP pode ser revogado a qualquer momento pela empresa, alterando as credenciais de API no próprio Omie.

8. Alterações nesta política

Esta política pode ser atualizada periodicamente. A data da última atualização será sempre indicada no topo desta página.

9. Contato
