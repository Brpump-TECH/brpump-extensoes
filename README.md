# brpump-extensoes
Gera propostas comerciais em PDF a partir de pedidos do Omie ERP. Busca automaticamente dados do cliente, vendedor, pagamento, frete e conta corrente. Suporte a duas empresas (Indústria e Comércio). Credenciais armazenadas apenas no dispositivo.

Repositório de suporte às extensões do Chrome publicadas pela BR Pump.
